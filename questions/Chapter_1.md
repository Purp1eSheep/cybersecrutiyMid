# Chapter 1｜資訊安全簡介

## 單選題

1. CIA 中的 C 代表什麼？

- (A) 完整性
- (B) 機密性
- (C) 可用性
- (D) 可稽核性

2. 某網站因 DDoS 而無法提供服務，主要影響哪項需求？

- (A) 機密性
- (B) 不可否認性
- (C) 可用性
- (D) 身分鑑別

3. 匯款金額遭未授權者修改，主要破壞哪項需求？

- (A) 完整性
- (B) 可用性
- (C) 機密性
- (D) 隱私權

4. 員工誤刪重要資料屬於何種威脅？

- (A) 天然且蓄意
- (B) 人為且無意
- (C) 天然且被動
- (D) 人為且必然蓄意

5. 攻擊者只偷看未加密通訊而不改變內容，較接近哪類攻擊？

- (A) 主動攻擊
- (B) 實體破壞
- (C) 被動攻擊
- (D) 阻斷服務

6. 哪項最適合用來保護學生只能查看自己的成績？

- (A) 公開所有成績
- (B) 停用稽核
- (C) 取消登入
- (D) 權限控管與最小權限

7. 下列何者屬於弱點，而不是已發生的攻擊？

- (A) 管理員使用預設密碼
- (B) 駭客竊取資料
- (C) 網站遭竄改
- (D) 伺服器遭勒索

8. 在風險分析中，應同時考量哪兩項？

- (A) 螢幕大小與品牌
- (B) 事件機率與可能損失
- (C) 員工人數與樓層
- (D) 資料筆數與檔名

9. 下列何者最能提供交易不可否認性的證據基礎？

- (A) 關閉紀錄
- (B) 共用帳號
- (C) 可驗證的數位簽章
- (D) 刪除交易明細

10. 資訊安全保護的範圍最適合如何描述？

- (A) 只保護伺服器
- (B) 只阻擋外部駭客
- (C) 只管理密碼
- (D) 資料、系統與營運

11. ISO/IEC 27001 主要對應哪項？

- (A) 資訊安全管理系統要求
- (B) 網路封包格式
- (C) 資料庫查詢語法
- (D) 加密金鑰長度表

12. 下列何者最接近威脅分析的問題？

- (A) 系統哪裡可能被利用、由誰如何攻擊？
- (B) 網站字體是否好看？
- (C) 資料庫有多少欄位？
- (D) 員工午餐如何安排？

13. 發現帳號共用與資料誤寄問題，哪個方案最合理？

- (A) 只購買更快主機
- (B) 停用全部備份
- (C) 個人帳號、適當授權與教育訓練
- (D) 公開所有資料

## 是非題

76. （ ）CIA 的 Availability 指系統在需要時能正常提供服務。

77. （ ）只要安裝防火牆，就能解決所有資訊安全問題。

78. （ ）攻擊者未授權修改網站內容，主要涉及完整性問題。

79. （ ）風險分析只需考慮攻擊發生機率，不必考慮損失。
