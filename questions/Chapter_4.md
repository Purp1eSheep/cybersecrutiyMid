# Chapter 4｜作業系統安全與存取控制

## 單選題

38. 存取控制最核心要回答的問題是？

- (A) CPU 有多快
- (B) 資料庫有多少筆
- (C) 誰可對何資源執行何動作
- (D) 網頁使用哪種顏色

39. Access Control 的 Subject 通常指？

- (A) 提出存取要求的使用者或程序
- (B) 被存取的檔案
- (C) 存取規則文件
- (D) 備份磁碟

40. DAC 的主要特徵是？

- (A) 由中央強制標籤決定
- (B) 資源擁有者可設定存取權限
- (C) 依工作角色統一指派
- (D) 所有人皆可存取

41. MAC 的主要特徵是？

- (A) 任何使用者都能改標籤
- (B) 只使用密碼
- (C) 沒有分類等級
- (D) 依安全標籤與許可等級強制控制

42. RBAC 的權限主要指派給什麼？

- (A) 網路線
- (B) IP 封包
- (C) 角色
- (D) 鍵盤

43. Bell–LaPadula 主要關注哪項安全目標？

- (A) 機密性
- (B) 效能
- (C) 能源效率
- (D) 資料壓縮

44. Bell–LaPadula 的 No Read Up 意味著？

- (A) 高權限者不可讀低密資料
- (B) 低許可等級者不可讀高機密資料
- (C) 所有人不可讀資料
- (D) 只有管理員可寫入

45. Bell–LaPadula 的 No Write Down 主要避免？

- (A) 資料遺失
- (B) 伺服器停機
- (C) 網路壅塞
- (D) 高機密資訊向低等級流出

46. 最小權限原則的正確做法是？

- (A) 所有帳號給管理員權限
- (B) 所有資料可公開
- (C) 只給完成工作所需權限
- (D) 取消帳號審核

47. Zero Trust 的核心精神是？

- (A) 永不預設信任，持續驗證
- (B) 內網一律可信
- (C) 驗證一次後永久可信
- (D) 只要 VPN 就不需授權

48. Linux 權限 r、w、x 對應的數值是？

- (A) 1、2、4
- (B) 4、2、1
- (C) 2、4、1
- (D) 7、5、3

49. Linux 權限 750 代表什麼？

- (A) 擁有者 rw、群組 r、其他 x
- (B) 擁有者 r、群組 rwx、其他無
- (C) 所有人 rwx
- (D) 擁有者 rwx、群組 r-x、其他無權限

50. Windows Core Isolation 的 Memory Integrity 主要屬於？

- (A) 檔案備份
- (B) 實體門禁
- (C) 作業系統防護機制
- (D) 使用者教育訓練

## 是非題

88. （ ）RBAC 是將權限與角色關聯，再將角色指派給使用者。

89. （ ）在 DAC 中，資源擁有者完全不能調整自己的資源權限。

90. （ ）Zero Trust 主張不因使用者位於內網就自動信任。

91. （ ）Linux 權限 777 符合所有敏感檔案的最小權限原則。
