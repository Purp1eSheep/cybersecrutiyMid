# Chapter 5｜對稱式密碼系統

## 單選題

51. 對稱式加密最主要的特徵是？

- (A) 加解密使用同一把祕密金鑰
- (B) 只有公鑰
- (C) 完全不需金鑰
- (D) 只能做簽章

52. 加密前可閱讀的資料稱為？

- (A) 密文
- (B) 明文
- (C) 雜湊值
- (D) 金鑰長度

53. XOR 運算中 1 XOR 1 的結果是？

- (A) 2
- (B) 1
- (C) 0
- (D) 不定

54. XOR 運算中 1 XOR 0 的結果是？

- (A) 0
- (B) 2
- (C) 錯誤
- (D) 1

55. 下列何者屬於古典替換式密碼的例子？

- (A) Caesar Cipher
- (B) AES-GCM
- (C) RSA-OAEP
- (D) ECDH

56. DES 的主要問題之一是？

- (A) 無法處理資料
- (B) 金鑰長度較短、已不適合現代安全需求
- (C) 不能被硬體實作
- (D) 是非對稱加密

57. AES 常見的金鑰長度為？

- (A) 40、56、64 位元
- (B) 64、96、128 位元
- (C) 128、192、256 位元
- (D) 256、512、1024 位元

58. ECB 模式的主要缺點是？

- (A) 一定無法解密
- (B) 只能加密文字
- (C) 需要公開私鑰
- (D) 相同明文區塊可能產生相同密文區塊

59. CBC 模式中的 IV 主要用於？

- (A) 使加密初始化具有變化性
- (B) 代替所有祕密金鑰
- (C) 公開明文
- (D) 當作數位簽章

60. 若加密模式需要同時驗證資料完整性，哪個選項較合適？

- (A) ECB
- (B) AES-GCM
- (C) 單純 XOR
- (D) Caesar Cipher

61. 對稱式加密在大量資料保護上的優點通常是？

- (A) 一定不需管理金鑰
- (B) 完全無法被破解
- (C) 效率較高
- (D) 自動提供不可否認性

62. 加密資料之前最重要的安全考量之一是？

- (A) 把金鑰放在密文旁邊明文保存
- (B) 永遠使用固定弱金鑰
- (C) 公開全部金鑰
- (D) 妥善保護與管理祕密金鑰

## 是非題

92. （ ）AES 屬於對稱式密碼演算法。

93. （ ）ECB 能保證相同明文區塊每次都產生不同密文區塊。

94. （ ）XOR 運算滿足 A XOR K XOR K = A。

95. （ ）只要資料經過加密，就不需要管理加密金鑰。
